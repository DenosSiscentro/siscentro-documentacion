# Siscentro - Centro de ayuda

Documentación oficial de Siscentro.

## Objetivo

Ofrecer manuales y guías de uso para trabajadores y administradores.

## Tecnologías

- HTML5
- CSS3
- JavaScript

No requiere frameworks ni dependencias externas.

## Estructura

- `index.html`: portada del centro de ayuda.
- `trabajador/`: manual del trabajador.
- `administrador/`: manual del administrador.
- `assets/css/`: estilos.
- `assets/js/`: funcionalidades JavaScript.
- `assets/img/`: capturas e imágenes.
- `pdf/`: manuales descargables.

## Desarrollo local

Abrir `index.html` en un navegador.

También se puede utilizar la extensión Live Server de Visual Studio Code.

## Publicación

El proyecto está preparado para desplegarse como sitio estático mediante Cloudflare Pages.
